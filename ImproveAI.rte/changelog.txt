2026/08/19 - 22h30
- Fr_Dae
- version 0.6 development work.
- Miner.lua remains a native GoldDig wrapper.
- MinerOptimized.lua uses explicit mining anchors, 12 px reference blocks and finite bottom-of-map protection.
- Constructor acquisition checks equipped and inventory tools before mining.
- Anchor.lua stores the mining origin and direction and provides optional debug drawing.
- Investigation of CCCP input handling shows that configurable keyboard actions are implemented through InputElements/InputScheme and the Settings Input Mapping GUI; adding a dedicated Rotate Anchor action therefore requires a CCCP source change rather than a Lua-only key binding.
- The default Rotate Anchor key is planned as R, with user remapping through the normal input settings.
- Anchor rotation must not be implemented as a hard-coded Lua-only KEY_R shortcut.
- README and CONTRIBUTOR.md document the architecture and CCCP Lua/C++ optimisation constraints.
